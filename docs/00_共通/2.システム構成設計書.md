# システム構成設計書

## システム構成図

```text
ブラウザ
   │
Next.js
   │
Spring Boot
 ├── Oracle
 ├── GDELT
 ├── Go
 └── Python
```

## サービス責務

| サービス    | 役割                   |
|-------------|------------------------|
| Next.js     | 画面                   |
| Spring Boot | 内部処理およびAPI処理  |
| Go          | APIによるデータ処理    |
| Python      | AIによる要約・文章生成 |

## 通信方式

| 通信          | 方式 |
|---------------|------|
| Next.js→Java | REST |
| Java→Next.js | REST |
| Java→GDELT   | REST |
| GDELT→Java   | REST |
| Java→Go      | REST |
| Go→Java      | REST |
| Java→Python  | REST |
| Python→Java  | REST |
