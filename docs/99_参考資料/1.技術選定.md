## 技術選定

### Java 21

Java 8での開発経験を踏まえ、
LTSであり現在も実務で広く利用されているモダンなJava環境を経験するためJava 21を採用。

### Spring Boot 4.1

Java 21との組み合わせで利用できる現行世代のSpring Bootを採用。
REST APIやマイクロサービス構成など、実務で利用されるSpring Boot開発を学ぶことを目的とする。

### React 19

現行世代のReactを採用し、
モダンなSPA開発や最新のReactの機能を学ぶことを目的とする。

### TypeScript 5.9

React 19と組み合わせる現行世代のTypeScriptを採用。
型安全なフロントエンド開発や保守性の高い実装を経験することを目的とする。

### Go 1.24

現行世代のGoを採用し、
大量データ処理や並列処理などGoの特徴を活かした開発を経験することを目的とする。

### Python 3.13

現行世代のPythonを採用し、
AI・データ分析を担当するサービスとして最新の開発環境を利用することを目的とする。

※ 2026年8月時点で、新規開発で採用しやすい安定版・LTS版を中心に選定しています。

# デプロイ環境・データベース比較

## 1. 絞り込み条件

### 共通条件

- 無料で利用できる、または無料プランが存在する
- 無料利用に明確な期限がない
- 一定期間後に無料プランが終了しない
- 一定期間後に有料プランへの移行が必須にならない
- 一定期間利用しないことでプロジェクト自体が削除されない
- 一定期間利用しないことで保存データが削除されない
- ポートフォリオを長期間維持できる

### 無料枠超過について

- 無料枠を超えた場合の挙動も確認する
- 利用制限・サービス停止になるサービス
- 従量課金になるサービス
- 自動的に有料プランへ移行するサービス
- それぞれを区別して評価する

# 6. データベース

## Oracle Autonomous AI Database

### 無料プラン

- Always Free
- 無料利用に期限なし

### 無料枠

- 最大2インスタンス
- 合計1 OCPU
- 合計20GBストレージ
- 最大同時セッション20

### 特徴

- Oracle Database
- マネージドデータベース
- SQLによるデータ操作
- Oracle Databaseの各種機能を利用可能

### 非アクティブ時の挙動

- 7日間非アクティブの場合、自動停止
- 停止後もデータは保持
- 停止状態が累積90日続くと削除される可能性がある

### 判定

- 条件付き候補

### 注意点

- 「非アクティブ停止・削除を一切認めない」という条件を厳密に適用する場合は除外対象
- 「自動停止するが一定期間データが保持される」という条件なら候補
